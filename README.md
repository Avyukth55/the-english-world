# The English World

A literary website for the School Literary Council.

## Publish with GitHub Pages

1. Open your `the-english-world` repository.
2. Choose **Add file → Upload files**.
3. Upload `index.html` from this folder (or upload the ZIP's contents, not the ZIP itself).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then save.
8. Wait for GitHub Pages to publish the site. The published address will appear in Settings → Pages.

## Important note about the Edit button

The current on-page Edit button saves changes only in the browser and device where they are made. It does not publish changes to the live website or share edits with other people. To update the public site, edit `index.html` in the GitHub repository and commit the change. We can improve the editing workflow after the first deployment.

## Privacy

This is a public website. Do not add private student information, personal contact details, or student submissions unless the school has approved publishing them.
